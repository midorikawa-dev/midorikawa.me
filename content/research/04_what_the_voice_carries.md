## 概要

03で一番効いたのは、教えることだった。けれど「教える」と言うとき、私は何かを当たり前に前提にしていた。教えるには、伝える手段がいる。ネズミにとって、それは声だ。

では、その声は何を運ぶのか。先に言ってしまうと、言葉ではない。ネズミの声は、文や命令ではなく、気分と状況を運ぶ。この記事では、実際のネズミの声をできるだけ本物に近づけて作り、それが何を伝えて、何を伝えないのかを見ていく。

## ネズミの声を、本物に近づける

これまで、群れの中の「声」は、ただの記号だった。危険を表す印が一つあるだけ。けれど本物のネズミの声は、もっと構造を持っている。だから、文献に書かれた特徴に合わせて作り直した。

ネズミの声は、人の耳にはほとんど聞こえない超音波<sup class="term-note">＊</sup>だ。そして、大きく二つの帯域に分かれる。低いほうの22kHz<sup class="term-note">＊</sup>は、長くて平らな声で、痛みや危険のときに出る。高いほうの50kHzは、短くて音程がくるくる動く声で、仲間といるときや遊んでいるときに出る。前者は「嫌だ」の声、後者は「いいぞ」の声だと思えばいい。

高いほうの声には、さらに細かい型がある。平ら、上がる、下がる、山なり、震える、と十種類ほどの「音節」だ。そして声は、でたらめには並ばない。ある音節の次に来る音節には、偏りがある。ゆるい文法のようなものがある。文献の統計をなぞると、私のモデルでも同じ特徴が出た。声は二つの帯域にきれいに分かれ、嫌悪の声は長く（中央値でおよそ900ミリ秒）、快の声は短く（およそ40ミリ秒）、音節の並びはランダムより秩序がある（遷移のばらつきは2.45で、順番をシャッフルした3.20より小さい）。

## 声は、思考ではなく気分を運ぶ

ここで大事なのは、何を運んでいないか、だ。

この声は、言葉ではない。「右にヘビがいる」のような、中身のある文は運ばない。運ぶのは、送り手の状態だ。怖がっているのか、落ち着いているのか。聞いた側は、その気分を読み取って反応する。22kHzを聞けば逃げ、50kHzを聞けば近づく。中身を読むのではなく、相手の状態を察する。

```python
def speak(self):
    # 声は内部状態（情動）から出る。命題ではない。
    band = "22kHz" if self.valence < 0 else "50kHz"
    return Call(band=band, syllable=self.pick_syllable())

def hear(self, call):
    # 聞いた側は、中身ではなく相手の状態に反応する
    self.flee() if call.band == "22kHz" else self.approach()
```

人の言葉と比べると、物足りなく見えるかもしれない。それでも、これで十分に多くのことができる。危険が群れの中を一瞬で伝わり、安心が場の空気を作る。

## 声で読めること、読めないこと

正直に言うと、これは本物のネズミの音声をそのまま再現したものではない。文献の統計的な特徴に形を合わせただけで、実際の鳴き声を合成しているわけではない。

そして、大事な留保がある。私がモデルにしたのは、ネズミの「気分」であって、「思考」ではない。声から読めるのは状態であって、頭の中ではない。この区別は、この先効いてくる。声が運ぶのは情動と文脈だ。意味や文化は、その上に積み上がっていく。

## 次へ

声は、文化の伝達手段になった。教える声、警告する声、群れをそろえる声。

だとすると、こう問える。その伝達手段に乗っているものは、どれくらい丈夫なのか。教える側がいなくなったとき、声に乗っていた知識はどうなるのか。次は、崩壊のときに本当に失われるものを見る。

## 補足

1. 超音波発声（USV）: ネズミが出す、人にはほとんど聞こえない高い周波数の声。録音して周波数を下げると聞こえる。
2. 22kHz / 50kHz 帯: 22kHz は長く平らで嫌悪や警報のとき、50kHz は短く音程が動き、社会や遊びのときに出る。Brudzynski や Panksepp による整理に基づく。
