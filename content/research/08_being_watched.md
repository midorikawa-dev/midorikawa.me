## 概要

前稿では、血縁ではない相手を仲間にする共有タグが、非血縁の協力を広げ、群れの崩壊を抑えることを見た。

しかし、協力が広がると別の問題が出る。

助けてもらうが、自分は助けない個体である。

助ける側はコストを払う。助けない側は、そのコストを払わずに利益だけを受け取る。このような個体が増えると、協力は内側から崩れる。

本稿では、見られていること、評判<sup class="term-note">＊</sup>が残ること、死後評価<sup class="term-note">＊</sup>を扱う。

ここで扱う「神」<sup class="term-note">＊</sup>は、信仰の内容や実体ではない。どこでも見られている、裏切れば見つかる、評価が死後も残る、という社会的な機能として扱う。

## 問い

協力は、どうやって保たれるのか。

前稿までのモデルでは、非血縁の相手にも援助が届くようになった。社会的能力の伝達は保たれやすくなり、群れは崩壊しにくくなった。

しかし、協力にはフリーライド<sup class="term-note">＊</sup>、つまりただ乗りの問題がある。

助けを受ける。だが、自分は助けない。援助のコストを払わない。短期的には、その個体の方が得をする。

もしそのような個体が増えれば、助ける側だけが損をし、協力は維持できなくなる。

では、何がただ乗りを抑えるのか。

ここでは、監視と評判を使う。

見られているなら、裏切りは見つかる。見つかれば助けてもらえなくなる。繁殖にも不利になる。

そのとき、裏切りは割に合わなくなる。

## 裏切る個体

モデルに、協力する個体と裏切る個体を置いた。

協力する個体は、条件が合えば他個体を助ける。時間や繁殖機会のコストを払う。

裏切る個体は、助けを受ける。しかし、自分からは助けない。

これは、個体だけを見ると有利である。

助けるコストを払わず、助けの利益だけを得るからである。

問題は、その個体が群れ全体を壊すかどうかである。

協力する個体が減れば、子が学べる機会が減る。社会的能力の伝達が弱くなる。群れは、また崩壊へ近づく。

## 見られていること

次に、裏切りが見つかる条件を変えた。

監視なし。

裏切りは見つからない。裏切る個体は助けを受け続け、自分はコストを払わない。

近くの個体による監視。

同じ場所に協力する個体がいれば、裏切りは見つかりやすくなる。ただし、誰も近くにいなければ見つからない。

どこでも見られている条件。

近くに誰がいるかに関係なく、裏切りは高い確率で見つかる。

この最後の条件を、本稿では「神」と呼ぶ。ただし、それは実体としての神ではない。どこでも見ている監視者という機能である。

## 変更点

変更点は小さい。

同じ物理装置、同じ共有タグ、同じ援助行動を使う。変えるのは、裏切りがどれだけ見つかるかである。

見ている関係は、次のように整理できる。

```text
裏切りの得 = 助けを受ける利益 - 見つかったときの不利益

見つかりやすいほど、裏切りは割に合わない。

裏切りが減る
→ 協力が残る
→ 子が学べる機会が残る
→ 群れが崩壊しにくくなる
```

条件だけを見るとこうなる。

```rust
let penalty = if cheating_is_seen {
    reputation_loss
} else {
    0.0
};

let cheating_gain = received_help - penalty;
```

さらに、死後にも評価が残る条件を加えた。

評価が生きている間だけなら、老いた個体は最後に裏切りやすくなる。先が短く、評判を失う不利益が小さいからである。

死後にも評価が残るなら、老いた個体も裏切りにくくなる。

## 結果

監視がない条件では、裏切る個体が増えた。

協力する個体の割合は下がり、群れの中にただ乗りが広がった。

近くの個体による監視は、ある程度は効いた。協力する個体の割合は上がった。ただし、群れが大きくなり、個体が散らばると、近くで見ている個体が減る。裏切りは見逃されやすくなる。

どこでも見られている条件では、協力する個体の割合がさらに保たれた。

本モデルでは、監視なしでは協力者の割合がおよそ0.47、近くの監視では0.63、どこでも見られている条件では0.70だった。

さらに、死後にも評価が残る条件を加えると、絶滅率がもっとも下がった。

## なぜ近くの監視では足りないか

近くの個体による監視は、小さい群れでは効く。

誰かが近くにいれば、裏切りは見つかる。見つかれば不利益を受ける。だから裏切りにくくなる。

しかし、群れが大きくなると状況が変わる。

個体は広い場所に散らばる。いつも近くに協力する個体がいるとは限らない。近くで見ている者がいない場所では、裏切りは見つからない。

つまり、人の監視は局所的である。

大きな群れでは、匿名性が生まれる。

どこでも見られている条件は、この弱さを補う。近くに誰がいるかに関係なく、裏切りは見つかる。

この意味で、本モデルの「神」は、信仰対象ではなく、大きな群れで評判を保つための機能である。

## 解釈

ここで見えているのは、宗教の正しさではない。

神が存在するかどうかを扱っているわけでもない。

扱っているのは、協力を維持する仕組みである。

誰かが見ている。裏切れば見つかる。評判が落ちる。助けてもらえなくなる。死後にも評価が残る。

そのような仕組みがあると、短期的に得をする裏切りが抑えられる。

協力が残れば、社会的能力の伝達も残る。子が学べる機会も残る。群れは崩壊しにくくなる。

本モデルでは、見られていることは道徳の飾りではなかった。

協力を保つための、実行可能な条件だった。

## 限界

このモデルは、現実の宗教や信仰を再現していない。

ここでいう「神」は、監視、罰、評判、死後評価という機能の組み合わせである。信仰の内容、儀礼、共同体、教義、経験は扱っていない。

また、協力するか裏切るかも単純化している。現実の協力は、もっと曖昧で、状況に依存する。

ここで扱ったのは、ひとつの仮説である。

大きな群れでは、見られていることと評判が、ただ乗りを抑え、協力の安定性を変えうる。

本モデルは、その仮説を実行可能な形にした。

## 次の問い

ここまでで、資源不足ではない崩壊、愛、仲間の境界、評判による協力の維持を扱った。

次に必要なのは、これらをひとつの弧として整理することだと思う。

群れはなぜ崩壊するのか。何が伝達をつなぎ直すのか。誰を仲間として扱うのか。協力はどう保たれるのか。

次稿では、この一連のモデルをまとめ、ラット群を使って何を見ようとしているのかを整理する。

## 補足

1. フリーライド: 他個体からの援助を受けるが、自分は援助コストを払わないこと。
2. 評判: 本稿では、裏切りが見つかった個体が助けてもらいにくくなり、繁殖にも不利になる効果として扱う。
3. 死後評価: 死後にも評価が残るという条件。本稿では、老齢個体の末期の裏切りを抑える機能として扱う。
4. 神: 本稿では、どこでも見られていること、罰、評判、死後評価をまとめた社会的機能を指す。実体や信仰内容を扱うものではない。
