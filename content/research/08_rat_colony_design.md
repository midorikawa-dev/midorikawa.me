## 概要

ここまでの稿では、崩壊、愛、仲間、評判、経験、記憶を順に見てきた。

しかし、それらは単独で存在しているわけではない。

個体は、どこかにいる。

誰かに近づく。

誰かを避ける。

誰かの近くで学ぶ。

つまり、このモデルには空間がある。

本稿では、AIラット群を、箱<sup class="term-note">＊</sup>、個体、行動更新として整理する。

## 問い

AIラット群では、何が作られているのか。

単に個体を並べているだけではない。

個体は、空間の中で動く。

巣<sup class="term-note">＊</sup>に戻る。

通路<sup class="term-note">＊</sup>を通る。

中央部<sup class="term-note">＊</sup>で他個体と接触する。

この配置によって、出会いやすい相手と、出会いにくい相手が生まれる。

それが、学習、信頼、裏切り、協力の条件になる。

## 箱

箱は、単なる背景ではない。

ここでの箱は、スキナー箱<sup class="term-note">＊</sup>の再現ではない。

個体が、どこで出会い、どこで避け、どこで学ぶかを見るための空間である。

箱の形は、個体同士の出会い方を変える。

広い空間では、個体は分散しやすい。

狭い空間では、個体はぶつかりやすい。

通路が細ければ、移動は詰まりやすい。

巣が分かれていれば、群れは小さなまとまりを持ちやすい。

つまり、空間の形は、社会の形に影響する。

このモデルでは、箱は環境であると同時に、相互作用を制限する条件である。

## 個体

個体は、固定された性格だけを持つわけではない。

位置を持つ。

記憶を持つ。

信頼を持つ。

近づくか、避けるか、助けるかを選ぶ。

その選択は、過去の経験によって少し変わる。

個体を複雑にしすぎると、何が効いているのか分かりにくくなる。

そのため、ここでは個体を、空間内の位置と、相手ごとの内部値を持つものとして扱う。

## 更新

群れは、一度に完成するものではない。

小さな更新<sup class="term-note">＊</sup>を繰り返す。

個体が動く。

相手に出会う。

助けるか、避けるか、裏切るかが起きる。

その結果が記憶に残る。

次の行動が少し変わる。

中心は、この繰り返しである。

```text
空間 → 出会い → 行動 → 経験 → 記憶 → 次の行動
```

構造は小さい。

```rust
struct Colony {
    space: BoxSpace,
    rats: Vec<Rat>,
}

fn step(colony: &mut Colony) {
    for rat in colony.rats.iter_mut() {
        rat.choose_action(&colony.space);
        rat.update_memory();
    }
}
```

ここで重要なのは、個体の内側だけで社会が決まるわけではないことである。

箱の形が、出会いを変える。

出会いが、経験を変える。

経験が、次の行動を変える。

## 結果

箱の形を変えると、同じ個体でも振る舞いが変わった。

狭い通路では、接触が増えた。

接触が増えると、協力も裏切りも増えた。

巣が分かれている場合、関係は局所的に残りやすくなった。

同じ相手と何度も会うため、信頼や記憶が働きやすい。

一方で、中央部が混み合う場合、個体は相手を選びにくくなった。

誰と出会うかが安定しないため、関係は蓄積しにくい。

空間は、単なる見た目ではなかった。

空間は、群れの学習条件を作っていた。

## 解釈

AIラット群で作っているのは、個体の集合だけではない。

個体、空間、記憶、行動が互いに更新される場である。

社会的役割は、最初から名前として与えられるものではない。

何度も同じ場所にいる。

何度も同じ相手に会う。

何度も助ける。

何度も避けられる。

その繰り返しの中で、役割のようなものが見えてくる。

この意味で、役割は個体の内側だけにあるのではない。

箱の形と、出会いの履歴の中にある。

## 限界

この設計は単純である。

現実のラットの身体、匂い、音、発達、疲労は入っていない。

箱も、現実の環境をそのまま写したものではない。

ここで扱っているのは、社会的な振る舞いがどのような条件から立ち上がるかを見るための最小限の構造である。

したがって、このモデルは現実を説明しきるものではない。

ただし、個体の性質だけでなく、空間と出会い方を変数として扱える。

そこに、このモデルの使い道がある。

社会モデルなのか。

それとも、コードによって生命や社会を考えるための道具なのか。

## 補足

1. 箱: 本稿では、個体が移動し、出会い、接触する環境を指す。
2. 巣: 個体が戻りやすい場所、または局所的なまとまりが生じる場所を指す。
3. 通路: 個体の移動や接触を制限する細い空間を指す。
4. 中央部: 複数の個体が集まりやすく、接触が増える場所を指す。
5. 更新: 一回の時刻で、移動、接触、行動、記憶の変化が起きること。
6. スキナー箱: 動物の行動を観察するための実験装置。本稿の箱は、その再現ではなく、相互作用を整理するための抽象的な空間として扱う。
