## 概要

前稿では、ここまでのモデルをひとつの流れとして整理した。

崩壊していたのは、個体数そのものではなく、伝達<sup class="term-note">＊</sup>だった。

では、その伝達されるものは何か。

これまでの記事では、それを社会的能力<sup class="term-note">＊</sup>と呼んできた。

ただし、社会的能力を最初から固定された値として置くと、モデルはまだ弱い。

有能な個体は最初から有能で、そうでない個体は最初からそうでない、というだけになってしまう。

本稿では、個体が経験によって少しずつ行動を変える条件を扱う。

社会的能力を、固定値ではなく、経験で変わるウェイト<sup class="term-note">＊</sup>として見る。

## 問い

個体は、経験から変わるのか。

助けられた個体は、次に他個体へ近づきやすくなるのか。

裏切られた個体は、次に距離を取るのか。

有能な成体の近くで育った子は、同じような行動を取りやすくなるのか。

これまでのモデルでは、こうした変化をかなり単純に扱っていた。

個体には社会的能力があり、それが高ければ育児や学習がうまくいく。

しかし、それだけでは、能力がどこから来るのかが見えにくい。

能力を固定値として置くのではなく、経験によって変わるものとして扱う必要がある。

## 固定値としての能力

固定値の能力は、扱いやすい。

個体ごとに、社会的能力の値を持たせる。

値が高い個体は、求愛、育児、援助、学習がうまくいきやすい。

値が低い個体は、それらが失敗しやすい。

この書き方でも、崩壊は見える。

有能な成体が減ると、子が学べなくなる。

学べない子が成体になると、次世代の能力が下がる。

ただし、この書き方では、能力がどの経験によって変わるのかが見えにくい。

個体が何を経験したかが、行動の変化として十分に戻ってこない。

助けられた経験も、裏切られた経験も、学べた経験も、ただの履歴になりやすい。

行動を変える力になりにくい。

## 経験で変わるウェイト

そこで、社会的能力を一つの値ではなく、ウェイトとして扱う。

ここでいうウェイトは、ある行動をどれくらい選びやすいかを表す値である。

たとえば、次のようなウェイトである。

```text
近づくウェイト
避けるウェイト
助けるウェイト
待つウェイト
学ぶウェイト
裏切るウェイト
```

個体は、状況を見る。

近くに誰がいるか。相手は血縁か。共有タグを持つか。過去に助けてくれたか。裏切ったか。

そのうえで、ウェイトに応じて行動を選ぶ。

経験が起きると、ウェイトが少し変わる。

この小さな変更を、ここでは更新<sup class="term-note">＊</sup>と呼ぶ。

助けられたなら、近づくウェイトや助けるウェイトが上がる。

裏切られたなら、その相手を避けるウェイトが上がる。

有能な成体の近くで学べたなら、学ぶウェイトが残る。

つまり、個体は一度で変わるのではない。

小さい更新を積み重ねる。

## 変更点

変えたのは一箇所である。

個体の社会的能力を、固定された値ではなく、経験で更新されるウェイトとして持たせる。

流れは単純である。

```text
経験 → ウェイトの更新 → 次の行動 → 次の経験
```

たとえば、経験は次のようにウェイトを変える。

```rust
if helped {
    weights.approach += 0.03;
    weights.help += 0.02;
}

if betrayed {
    weights.avoid += 0.05;
}

if learned_from_adult {
    weights.learn += 0.03;
}
```

重要なのは、経験を説明として残すだけではなく、次の行動を変える値として戻すことである。

この変更で、社会的能力は個体の中に閉じた性質ではなくなる。

関係の中で変わる性質になる。

## 結果

経験による更新を入れると、群れの差が出やすくなった。

安定した群れでは、助けられる経験と学べる経験が残る。

その経験が、次の行動を少し協力的にする。

協力的な行動が増えると、さらに学べる機会が残る。

この循環は、群れを保つ方向に働く。

一方で、崩壊に近い群れでは逆の循環が起きる。

裏切られる。避ける。学べる相手が減る。助けるウェイトが残らない。

その結果、個体数が残っていても、関係の中身が薄くなる。

社会的能力は、最初から失われていたのではない。

更新される機会を失っていた。

## 何が見えるようになるか

この変更で、崩壊の見え方が少し変わる。

以前は、有能な成体が減ると、子が学べなくなる、と見ていた。

今回は、その間にもう一段入る。

子は、経験によってウェイトを作る。

つまり、子が有能な成体に近づけないということは、単に知識を受け取れないという意味ではない。

近づく、待つ、助ける、学ぶ、といったウェイトを更新できないという意味である。

この違いは大きい。

社会的能力は、情報ではなく、次の行動を選びやすくするウェイトとして残る。

誰といたか。

誰に助けられたか。

誰に裏切られたか。

何を試して成功したか。

そうした経験が、次の行動の確率を少しずつ変える。

## 解釈

ここで扱っているのは、賢い個体を作ることではない。

個体が大きな推論をするわけでもない。

扱っているのは、小さい更新である。

よかった経験を少し強める。

悪かった経験を少し避ける。

学べた相手の近くに残る。

それだけでも、群れの振る舞いは変わる。

社会的能力は、個体の中に最初から入っているものではなく、環境と関係の中で作られる。

この見方を入れると、崩壊はさらに伝達の問題として見える。

伝達とは、言葉や情報だけではない。

経験を通じて、次の行動を選ぶウェイトが変わることでもある。

## 限界

このモデルの学習は、まだかなり単純である。

報酬も罰も粗い。

記憶も短い。

相手を理解しているわけではなく、経験に応じてウェイトを動かしているだけである。

それでも、固定値だけのモデルよりは、見えるものが増える。

社会的能力が、どの関係の中で保たれ、どの関係の中で失われるのかを見やすくなる。

今はまだ、学習と呼ぶには小さい。

しかし、崩壊を見るためには、この小ささで十分な場合がある。

## 次の問い

経験で行動が変わるなら、次に見るべきなのは記憶である。

個体は、どれくらい過去を持つのか。

一度裏切られた相手を、いつまで避けるのか。

助けてくれた相手を、どれくらい覚えているのか。

記憶が短い群れと、記憶が長い群れでは、協力の形が変わるはずである。

次稿では、記憶の長さを扱う。

## 補足

1. ウェイト: 本稿では、ある行動を選びやすくする内部値を指す。プログラム上のweightである。固定された性格ではなく、経験によって少しずつ変わる。
2. 更新: 経験のあとに、ウェイトを少し変えること。ここでは大きな推論ではなく、単純な強化と抑制として扱う。
3. 社会的能力: 他個体と関わり、繁殖、育児、援助、学習を成立させる能力。本稿では、複数のウェイトの組み合わせとして見る。
4. 伝達: 子が成体から情報を受け取るだけでなく、経験を通じてウェイトを獲得することも含む。
