## 概要

前稿では、個体が経験によってウェイトを変える条件を扱った。

助けられる。裏切られる。学べる。

その経験が、次の行動を少し変える。

では、その経験はどれくらい残るのか。

本稿では、記憶<sup class="term-note">＊</sup>の長さを扱う。

ここでは、経験が残る時間を記憶の長さ<sup class="term-note">＊</sup>と呼ぶ。

記憶が短ければ、個体はすぐに忘れる。

記憶が長ければ、過去の相手を覚え続ける。

どちらが協力を安定させるのか。

## 問い

協力には、記憶が必要なのか。

前稿のモデルでは、経験によってウェイトが変わった。

しかし、経験がすぐ消えるなら、変化は残らない。

助けてくれた相手を忘れる。

裏切った相手も忘れる。

その場合、個体は毎回ほとんど初対面のように振る舞う。

一方で、記憶が長すぎる場合も問題がある。

一度裏切った相手を、いつまでも避ける。

過去の失敗が残り続ける。

関係が修復<sup class="term-note">＊</sup>されにくくなる。

つまり、記憶は長ければよいとは限らない。

## 短い記憶

まず、短い記憶を考える。

個体は直近の経験だけを持つ。

助けられれば少し近づきやすくなる。

裏切られれば少し避けやすくなる。

しかし、その変化はすぐに薄れる。

この条件では、協力は立ち上がりにくい。

助けた相手が、次にまた助け返してくれるとは限らない。

裏切った相手も、すぐに元の相手として扱われる。

関係が蓄積しない。

群れの中で協力が残るには、少なくとも少しの過去が必要になる。

## 長い記憶

次に、長い記憶を考える。

個体は、過去の相手を長く覚える。

誰が助けたか。

誰が裏切ったか。

誰の近くで学べたか。

この条件では、協力は安定しやすい。

助けた相手は信頼されやすくなる。

裏切った相手は避けられやすくなる。

ただし、長い記憶にも副作用がある。

一度の裏切りが、長く残りすぎる。

状況が変わっても、相手を許しにくい。

記憶が強すぎると、関係が固定される。

協力は守られるが、回復の余地は小さくなる。

## 変更点

変えたのは、経験が残る時間である。

個体は相手ごとに記憶を持つ。

助けられた記憶は、信頼<sup class="term-note">＊</sup>を少し上げる。

裏切られた記憶は、信頼を下げる。

時間が経つと、記憶は少しずつ弱くなる。

流れは単純である。

```text
経験 → 記憶に残る → 信頼が変わる → 次の行動が変わる
```

条件だけを見るとこうなる。

```rust
memory.retain(|event| event.age < memory_span);

if other.helped_me {
    trust[other] += 0.04;
}

if other.betrayed_me {
    trust[other] -= 0.08;
}
```

重要なのは、経験が永遠に残るわけでも、すぐ消えるわけでもないことである。

どれくらい残るかが、協力の形を変える。

## 結果

短い記憶では、協力は不安定だった。

助け合いが起きても、関係として残りにくい。

個体は相手を選びにくく、裏切りも抑えにくい。

その結果、協力する個体の割合は揺れやすくなった。

中程度の記憶では、協力がもっとも安定した。

助けた相手は信頼される。

裏切った相手は避けられる。

しかし、時間が経つと記憶は薄れるため、関係が完全には固定されない。

長すぎる記憶では、裏切りは抑えられた。

ただし、関係の修復も起きにくくなった。

一度悪い記憶を持たれた個体は、長く避けられる。

群れは安定するが、硬くなる。

## 解釈

記憶は、協力を支える。

しかし、記憶は単なる保存ではない。

どの経験を、どれくらい残すかである。

短すぎれば、関係は積み上がらない。

長すぎれば、関係は変わりにくくなる。

このモデルでは、協力を保つには、忘れないことだけでなく、忘れることも必要だった。

忘れることで、関係は修復される。

覚えることで、裏切りは抑えられる。

その両方の間に、協力が残る範囲がある。

## 限界

ここで扱った記憶は単純である。

個体は、相手ごとの信頼を持つだけである。

出来事の意味を解釈しているわけではない。

謝罪も、儀礼も、説明もない。

現実の記憶はもっと複雑である。

それでも、記憶の長さを変えるだけで、協力の安定性は変わった。

これは、社会的能力が経験だけでなく、経験の残り方にも依存することを示している。

## 補足

1. 記憶: 本稿では、個体が相手ごとに保持する過去の経験を指す。
2. 信頼: 本稿では、相手に近づくか、助けるか、避けるかを変える内部値として扱う。
3. 記憶の長さ: 経験が行動に影響し続ける時間を指す。
4. 修復: 一度悪くなった関係が、時間や新しい経験によって戻ること。
